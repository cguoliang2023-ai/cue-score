# 一杆记分（iPhone 离线版）

这是一个无需账号、无需服务器的台球记分 PWA。对局资料、头像和分数只保存在本机浏览器中。

## 已有功能

- 斯诺克、中式 8 球、追分、自定义计分
- 2–4 人、姓名录入、从手机相册选择头像
- 当前回合提示、快捷加/减分、撤销、得分记录和本局结算
- 安装后可离线使用

## 安装到 iPhone

PWA 必须以网页形式打开；不能直接把文件夹拷入“文件”App 后运行。

1. 将这个项目上传到任意 HTTPS 静态网站托管服务（例如 GitHub Pages、Cloudflare Pages 或自己的空间）。
2. 用 iPhone Safari 打开对应网址。
3. 点 Safari 的“分享”按钮，选择“添加到主屏幕”。
4. 从主屏幕打开“一杆记分”。首次打开后即可离线使用。

如仅在家中测试，也可先在电脑启动一个本地网页服务器，再让 iPhone 与电脑连接同一 Wi-Fi 后用 Safari 打开电脑局域网地址；正式安装与离线缓存推荐 HTTPS。

## 隐私

不含登录、分析脚本或云端数据库。头像会被压缩前的原图编码存入 Safari 本地存储，建议选较小的头像照片。
